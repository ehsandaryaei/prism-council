# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticize ideas rather than people, and do not harass anyone. Disagreement is welcome here, since it is the point of a council. Personal attacks are not.

## Reporting

Report unacceptable behavior privately to the maintainer through the contact options on [the maintainer's GitHub profile](https://github.com/ehsandaryaei). If the behavior happens in an issue or pull request, you can also report the comment to GitHub. Reports are handled confidentially.

The maintainer may remove comments, close issues, or block contributors who violate this code.
